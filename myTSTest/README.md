# myTSTest — TypeScript 基础练习

Vite + TypeScript 沙箱，练习 TS 类型系统基础。

## 练习内容

- **原始类型** — `number`、`string` 类型标注
- **接口 (Interface)** — 定义对象形状、嵌套接口
- **类型推断** — TS 自动推断与显式标注对比
- **DOM 类型** — `HTMLImageElement` 等 DOM 类型断言

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | TypeScript 6.0 |
| 构建 | Vite 8 |
| 打包 | Rolldown |

## 快速开始

```sh
cd myTSTest
npm install
npm run dev
```
